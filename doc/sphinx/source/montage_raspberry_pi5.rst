Montage de la Raspberry Pi 5
============================

Cette section décrit le montage matériel de la Raspberry Pi 5
utilisée comme contrôleur principal du système.

Étapes de montage
-----------------

- Installation du dissipateur thermique
- Fixation dans le boîtier
- Connexion de l’alimentation
- Connexion des périphériques (USB, HDMI)

Vérifications
-------------

- LED d’alimentation
- Démarrage correct
